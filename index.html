ℹ️ Что такое Global ID?

Global ID — это уникальный идентификатор пользователя в экосистеме IT Global. Он используется во всех сервисах: GloBank, Айсберг, и будущих продуктах. Один ID — доступ ко всем сервисам.

🔒 Ваши данные защищены
Все данные хранятся в зашифрованном виде. Только вы имеете к ним доступ.
