Global ID — очистка Firestore

Инструмент для ручного аудита документов в проекте glob-data.

Важно: автоматическое удаление «неиспользуемых» данных отключено. По одному коду сайта нельзя надёжно определить, что документ больше не нужен. Удаление документа также не гарантирует удаление его подколлекций. Сначала экспортируйте резервную копию в Firebase Console.

Вход администратора

Выбор коллекции

Системные коллекции users и global_ids специально не доступны для удаления через эту страницу.

Сначала выберите коллекцию и нажмите загрузку.

Удаление доступно только после входа в аккаунт с role=admin в users/{uid}. Список ограничен первыми 100 документами; наличие документа в списке не означает, что он не используется.
